# 省医成功完成一例带神经血管蒂胸大肌移植肱二头肌再造术

> 更新时间：2026-09-16 (UTC+8)

**点击蓝字 关注“贵州省人民医院”**

  11月24日，记者从贵州省人民医院获悉，贵州省人民医院神经外科周围神经治疗小组团队于9月19日完成1例肌肉再造手术：带神经血管蒂胸大肌转位肱二头肌功能重建术。

  19岁的小新（化名）因右上臂内侧受伤就诊于贵州省人民医院，经检查，小新右侧肌皮神经损伤、肱二头肌失用性萎缩。

  经过省医综合评估后采取右侧胸大肌转位重建肱二头肌功能，手术难度在于显微镜下完整剥离胸大肌肌瓣保护该肌供血动静脉、神经。对病人及手术医生都是严峻的考验。

  在贵州省人民医院麻醉团队和手术室护士的密切配合“保驾护航”下，手术历时4小时顺利完成。

  患者术后生命体征平稳，剥离胸大肌及附动静脉神经完整，转位重建后再造的肱二头肌血运正常，术末电刺激肌肉收缩功能正常。患者恢复良好，康复出院。

  术后2个月小新解除石膏外固定，右上肢可主动屈曲。
